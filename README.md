# 📦 模型取景台

这是一个在浏览器里查看 GLB 模型、调整镜头并导出高清 PNG 的小工具。

它特别适合包装盒、产品外观、展示模型这类需要反复确认角度和出图的工作。网页可以在本机使用，也可以分享给同一局域网里的手机、平板和其他电脑。模型渲染与图片导出都在访问者的浏览器中完成，不会上传到远程服务器。🔒

## ✨ 能做什么

- 按文件夹管理和切换多个 GLB 模型。
- 首页显示最多 10 个最近添加的模型，点击即可打开。
- 用鼠标或触摸旋转、缩放和平移模型。
- 精确调整水平角、俯仰角、相机距离和 FOV。
- 调整 FOV 时自动补偿相机距离，尽量保持模型在画面中的大小不变。
- 阻止相机穿进模型内部，同时允许镜头尽量贴近模型表面。
- 使用取景框预览最终出图范围，浏览器窗口比例和导出比例不同时也不怕看错构图。
- 导出 64～8192 像素的无损 PNG，支持透明背景和常用分辨率预设。
- 使用显卡支持的最高各向异性过滤，并提供标准和高质量（FXAA 抗锯齿）导出。
- 调整 HDRI、曝光、阴影和色调映射；HDRI 默认去色，服务主机可把当前光照保存为所有人的项目默认值。
- 在服务主机上右键模型卡片，自动生成规范缩略图。
- 通过中文启动器检查依赖、启动、停止、查看状态和清理运行环境。

## 🚀 最快上手

### 1. 安装项目专属运行环境（推荐）

双击项目根目录的 `启动服务.bat`，选择：

```text
[1] 一键安装项目运行环境与依赖
```

启动器会从 Node.js 官方网站下载 Node.js 22 LTS，校验安装包后放进项目自己的 `.runtime/node/`，再把 npm 依赖安装到 `node_modules/`。npm 下载缓存也只放在 `.runtime/npm-cache/`。

这套方式不需要管理员权限，不修改系统 `PATH`，也不会把依赖装进其他文件夹。电脑已经安装了 Node.js 也没关系：启动器会优先使用项目内版本。需要联网的只有首次安装或依赖发生变化时。📦

如果不想下载项目专属环境，也可以自行安装较新的 Node.js；启动器找不到项目内版本时会自动使用系统版本。

### 2. 检查环境和依赖

在中文菜单中选择：

```text
[2] 检查运行环境和依赖
```

检查结果会说明当前使用的是“项目内”还是“系统”Node.js。如果只有 npm 依赖缺失，可以按照提示修复；也可以在项目目录打开 PowerShell，手动运行：

```powershell
npm install
```

### 3. 启动网页

在启动器中选择：

```text
[3] 启动局域网服务
```

启动成功后会显示两个地址：

- `http://localhost:5173/`：这台电脑自己访问。
- 类似 `http://192.168.1.10:5173/`：同一局域网中的其他设备访问。

把局域网地址发给同事，连接同一个路由器或 Wi-Fi 后即可打开。📱💻

如果其他设备打不开，请在 Windows 防火墙提示中允许 Node.js 访问“专用网络”，并确认路由器没有开启“客户端隔离”。

## 📁 怎样添加模型

把 `.glb` 文件放进项目的 `models` 文件夹。里面可以继续建立任意层级的分类文件夹，中文和空格都支持：

```text
models/
├─ 包装盒/
│  ├─ 产品A.glb
│  └─ 产品B.glb
└─ 展示架/
   └─ 金属/
      └─ 展示架.glb
```

添加、删除或移动模型以后，请重启服务。网页会重新扫描模型，不需要手写模型清单，也不需要修改代码。

> 建议让 GLB 自带完整材质。外置贴图也可以使用，但必须保持 GLB 中记录的相对路径关系。

## 🔄 怎样添加360°图片

在 `image_sequence` 中为每个产品建立一个文件夹，并按“名称、俯角、帧号”命名 PNG：

```text
image_sequence/
└─ 产品A/
   ├─ 产品A_俯角0_0001.png
   ├─ 产品A_俯角0_0002.png
   └─ 产品A_俯角5_0001.png
```

启动和构建网页时不会自动生成预览图。未构建的产品会显示提示 icon；在运行服务的电脑上右键产品或文件夹，也可进入“批量选择”，然后按目标最长边并行构建 WebP 缓存。源 PNG 变化后不会自动判定缓存过期，需要更新时可主动重新构建。产品库每次刷新都会自动清理已删除源文件对应的缓存。

网页预览使用 WebP，点击“保存原始 PNG”仍会下载对应的原始文件。左右拖动可循环旋转，上下拖动切换俯角，滚轮或双指可缩放。局域网设备可查看已构建内容，但不能发起构建任务。

## 🖼️ 模型封面与自动缩略图

模型卡片的封面按下面的顺序查找：

1. 与模型同名的专属封面，例如 `产品A.cover.webp`。
2. 当前文件夹的公共封面，例如 `cover.webp`。
3. 如果都没有，就显示统一的 `3D` 占位图。

封面支持 `.webp`、`.png`、`.jpg` 和 `.jpeg`。

在运行服务的电脑上，右键模型卡片并选择“自动生成缩略图”，网页会：

- 使用统一的默认角度和浅灰背景；
- 生成 640×480 WebP；
- 保存为 `<模型文件名>.cover.webp`；
- 已有同名封面时直接覆盖；
- 完成后立即刷新卡片，不影响当前正在查看的模型和相机。

为了防止别人误改项目文件，局域网中的其他设备只能查看，不能生成或覆盖缩略图。手机和平板也不会通过长按触发这个功能。🛡️

## 🎮 怎样操作模型

| 操作 | 效果 |
| --- | --- |
| 鼠标左键拖动 | 旋转模型 |
| 鼠标滚轮 / 触控板 / 双指 | 拉近或拉远相机，不改变 FOV |
| 鼠标右键拖动 | 平移观察目标 |
| 右侧相机面板 | 精确输入角度、距离和 FOV |
| 重置视角 | 恢复默认角度、45° FOV 和自动取景 |

相机会尽量靠近模型，但不会停在模型包围盒内部。调整 FOV 时，网页会自动改变相机距离，让模型在画面中的大小尽可能保持一致；如果已经贴近模型表面，页面会限制无法继续补偿的 FOV，并给出提示。

## 📸 怎样导出图片

1. 输入想要的宽度和高度，或者点击常用分辨率。
2. 看预览区中央的亮色取景框——框内就是最终 PNG 的构图。
3. 根据需要调整背景颜色、透明背景和“导出质量”。
4. 点击“导出 PNG”。

支持的尺寸范围是 64×64 到单边 8192 像素，常用分辨率中包含 8192 × 8192（8K），也支持横图、竖图和自定义比例。导出文件名会自动包含模型名、分辨率和时间。

导出面板会显示当前设备报告的 WebGL 单边尺寸上限，取纹理和渲染缓冲上限中较小的值。该值表示浏览器可申请的理论尺寸；复杂模型的完整出图仍取决于显卡、驱动和浏览器。

导出前还会检查当前查看器的实际 WebGL 绘制缓冲尺寸；如果它小于请求尺寸，导出不会保存一张被裁剪的 PNG，而会自动将宽高填为实际支持的尺寸，可直接再次点击导出。

### “导出质量”怎么选？

- **标准（首次默认）**：使用自适应 mipmap 和显卡支持的最高各向异性过滤，适合大多数出图。
- **高质量（FXAA）**：在最终尺寸上仅对高对比边缘做自适应平滑，不改变构图、背景颜色或 PNG 尺寸。浏览器会记住你的选择。

“贴图锐度”独立于导出质量：标准档默认使用“自适应（更稳定）”，高质量档默认使用“原图优先（更锐利）”。原图优先锁定纹理基础层，可保留斜面上的文字和细线；纹理本身细密、距离很远或角度极斜时，可能增加闪烁或摩尔纹。

预览和导出会使用设备支持的最高纹理过滤质量，但最终清晰度仍取决于源贴图分辨率、观察角度、输出尺寸和显卡能力。工具不会凭空生成原始贴图里不存在的细节。

4K、4096×4096 或 8192 像素图片会占用较多显存。如果浏览器提示导出失败，请降低尺寸或换到显卡能力更强的电脑。

## 💡 怎样统一默认光照

在右侧“渲染工作室”中选择环境光并调整曝光、阴影、色调映射和“HDRI 去色”。去色默认开启，会保留 HDRI 的明暗关系，同时消除环境贴图给模型带来的颜色偏移。开启“预览 HDRI 背景”后，取景区会显示当前环境全景；三轴环境旋转可分别调整俯仰 X（-180°～180°）、水平 Y（0°～360°）和翻滚 Z（-180°～180°），背景、反射与光照会同步，带地面的天空盒只跟随水平旋转。

HDRI 背景只用于交互取景预览，不改变现有 PNG 输出规则：导出仍由“透明背景”和背景颜色控制。自动模型封面也继续使用统一浅灰背景。

运行服务的电脑会显示可用的“保存为默认”按钮。点击后，当前光照写入项目的 `config/default-lighting.json`；之后所有设备首次打开模型时都会读取同一套默认光照。每个浏览器已经针对某个模型调整并保存过的光照仍优先保留。局域网其他设备只能读取默认值，不能改写项目配置。

## 🧰 中文启动器菜单

双击 `启动服务.bat` 后可以使用：

| 选项 | 用途 |
| --- | --- |
| 1 | 把 Node.js 22 LTS、npm 缓存和网页依赖全部安装到当前项目 |
| 2 | 检查项目内/系统 Node.js、npm、模型和项目依赖 |
| 3 | 启动局域网服务并显示访问地址 |
| 4 | 查看服务是否运行、端口是否被其他程序占用 |
| 5 | 停止局域网服务 |
| 6 | 删除项目内 Node.js、npm 缓存、依赖、构建结果和日志 |
| 7 | 只清理构建缓存和日志，保留运行环境与依赖 |
| 0 | 退出启动器 |

### 🗑️ 删除项目运行环境会删除什么？

选择 `[6]` 并输入 `REMOVE` 后，只会删除当前项目内可重新下载或生成的内容：

- `.runtime/` 中的项目专属 Node.js 和 npm 缓存；
- `node_modules/` 依赖；
- `dist/` 构建结果；
- `.vite/` 临时缓存；
- 服务 PID 和日志。

它不会卸载系统 Node.js，不会删除 `models/` 中的模型、贴图、缩略图，也不会删除源码、配置、文档和 Git 数据。以后再次选择 `[1]` 即可完整恢复。🛡️

选择 `[7]` 是更轻量的日常清理，只删除构建结果、Vite 缓存和日志，保留 `.runtime/` 与 `node_modules/`，下次启动无需重新下载依赖。

## 🛠️ 命令行方式

不想使用启动器，也可以在 PowerShell 中运行：

```powershell
# 安装依赖
npm install

# 启动开发服务，允许局域网访问
npm run dev

# 运行项目测试
npm run test:camera
npm run test:camera-application
npm run test:shared-camera
npm run test:vertical-shift
npm run test:vertical-shift-projection
npm run test:vertical-shift-browser
npm run test:thumbnail
npm run test:lighting

# 生成生产版本
npm run build

# 预览生产版本，允许局域网访问
```

生产构建结果位于 `dist/`。也可以在 `启动服务.bat` 中选择“构建静态部署包”。构建完成后，将整个 `dist/` 文件夹复制到目标 Windows 电脑，双击其中的 `启动静态服务.bat`，然后在浏览器打开 `http://localhost:5173/`，或使用启动窗口显示的局域网地址。首次启动时，请在 Windows 防火墙提示中允许 PowerShell 通过专用网络。该部署方式不需要安装 Node.js、npm 或项目依赖。

## ❓ 常见问题

### 新模型为什么没有出现？

模型清单在服务启动或生产构建时生成。放入新 GLB 后，请停止并重新启动服务。

### 别人的电脑为什么打不开网页？

确认两台设备连接同一个局域网，并使用启动器显示的局域网地址，而不是 `localhost`。还要允许 Node.js 通过 Windows 专用网络防火墙。

### 为什么局域网设备不能生成缩略图？

这是安全限制。只有运行服务的主机可以向项目文件夹写入封面，其他设备保持只读。

### 为什么高分辨率导出失败？

浏览器和显卡可能无法一次创建那么大的 WebGL 画布。降低输出尺寸、关闭其他占用显存的软件，或者换一台设备再试。

### 启动失败时去哪里看原因？

先在启动器中选择“查看服务状态”，再检查项目根目录中的：

- `.glb-viewer-output.log`
- `.glb-viewer-error.log`

服务默认使用 `5173` 端口。如果该端口已经被其他程序占用，启动器会明确提示。

## 🔐 隐私与限制

- 没有远程 API、数据库或云端上传。
- 模型查看与 PNG 生成都在访问者浏览器中完成。
- 缩略图和默认光照写入接口只允许服务主机使用。
- 防穿模以模型的轴对齐包围盒为边界，不是逐三角形碰撞检测。
- 最终质量无法超过模型和源贴图本身提供的信息。
