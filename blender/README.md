# GLB Web 360° 序列导出

在 Blender 5.1.2 中围绕产品渲染一圈或多圈 PNG。每圈对应一个俯角，输出可直接放进 GLB Web 的 360° 产品库。

## 安装与使用

1. 在 Blender 打开 **编辑 → 偏好设置 → 获取扩展**，从右上菜单选择 **从磁盘安装**，选择 `glb_orbit_export-1.3.1.zip`。安装时启用扩展。
2. 在 3D 视图按 `N`，打开 **GLB Web → 360° 产品序列**。选中产品或其父级，点击 **添加取景相机**。扩展会根据产品大小摆好相机和目标点。
3. 用 **选中相机** 或 **选中目标点** 选中对应对象，按 `G` 调整位置。相机始终朝向目标点。用 **查看相机取景** 看构图，满意后点击 **确认取景**。确认会记录轨道中心、相机距离、起始方位和镜头设置。调整后可以重新确认。
4. 在 **序列设置** 选择 **转相机** 或 **转物体**，再设置俯角、每圈帧数和分辨率。默认是 5°、15°、30° 各 36 帧。俯角允许负数和小数，例如 `-10, 5, 22.5`。各圈使用输入的俯角，首帧方位来自已确认相机。
5. 点击 **检查视角 · 已关闭 → 进入预览**，在当前 3D 视图检查所选帧。再点 **检查视角 · 已开启** 返回原视图。关闭时也可以选择俯角、切换帧或点击帧号跳转，打开检查后会显示所选帧。用 **渲染此帧** 检查灯光、材质和合成结果，预览最长边为 640 像素。
6. 填写产品名称，选择项目根目录、`image_sequence` 或其下的分类目录，点击 **渲染完整序列**。侧栏可查看进度或取消。渲染完成后刷新 GLB Web，在 **360° 图片** 中选择产品即可查看。

已确认后，点击 **重新取景** 可从原构图继续调整。插件会打开现有取景相机的视图。移动相机或目标点后，点击 **确认取景**，然后就可以检查视角或开始渲染。

同一个场景可以为多个产品分别取景。在 **取景相机 → 产品** 中切换到另一个物体或其父级，再点击 **添加取景相机**。切回已有产品时，插件直接使用它的相机、目标点和取景确认。视口预览和渲染都使用当前产品的取景，序列与输出设置由场景共用。升级后，旧版 `.blend` 中已经建立的取景可继续使用。

大纲中的 `GLB Web · 360°` 集合下设 `取景` 和 `预览`。前者存放可编辑的相机与目标点，后者用一台相机切换所有预览角度。点击 **退出相机视图** 返回原视图。取景确认和正在重新取景的状态都会随 `.blend` 保存，场景主相机继续用于正常 Blender 渲染。

Blender 5.1 的 Cycles 在渲染视口里会读取场景主相机的镜头参数。扩展在此模式下临时将插件当前显示的相机设为场景相机，保证它与实体视图构图一致。同一场景里跟随主相机的视口也会暂时跟随这台相机。退出预览、切回实体、保存文件或启动正式渲染时会还原主相机。Blender 5.2 起由 Cycles 直接读取视口相机。

**序列设置** 右上角的 **?** 可查看拍摄方式、俯角和帧数的说明。添加或确认取景、开启视角检查和启动渲染时，弹窗会说明操作的作用，确认后执行。

**转相机**是默认模式，产品和摄影棚固定，由相机绕拍。**转物体**在视口和正式渲染中都固定每组俯角的相机方位，让产品及其子物体绕确认的目标点转动。多零件产品请选共同父级，摄影棚灯光、地面等布景请放在产品层级之外。退出相机视图、切换拍摄方式、保存或开始后台渲染时，临时预览旋转会恢复到原姿态。

约束仍会求值。若棚灯通过约束追踪产品，可将约束目标改为固定的取景目标点。外部库链接的产品可通过本地集合实例拍摄，实例内的灯光和相机需移到独立布景中。受活动刚体模拟控制的产品应先将当前姿势转成可编辑物体。

例如产品名为 `样品` 时，首帧为 `image_sequence/样品/样品_俯角5_0001.png`。重新渲染同名产品前请移走旧产品目录，完成后在网页重新选择该产品。

单帧预览和完整序列都沿用场景的合成开关、胶片透明和色彩管理设置。启用合成时，PNG 使用合成器「组输出」的最终图像。序列统一保存为 PNG，沿用兼容的颜色模式和位深。需要保留 Alpha 通道时，请在 Blender 输出设置中选择 **RGBA**。

扩展只写产品序列或单帧预览。合成器的「文件输出」节点在后台副本中停用，避免各角度以同一时间轴帧号覆盖辅助文件。后台进程也会绕过视频序列编辑器并禁用 `.blend` 中的自动执行脚本。边界检查使用视口求值的几何包围盒，可用 **渲染此帧** 核对渲染时的形变和遮挡。

## 构建与验证

在仓库根目录执行。将示例中的 `blender` 或 `BLENDER_BIN` 换成 Blender 5.1.2 的可执行文件路径即可。

```powershell
New-Item -ItemType Directory -Force blender/dist | Out-Null
blender --factory-startup --command extension build --source-dir blender/glb_orbit_export --output-dir blender/dist
blender --factory-startup --command extension validate blender/dist/glb_orbit_export-1.3.1.zip

$env:BLENDER_BIN = 'C:\Path\To\blender.exe'
npm run test:sequence
npm run test:blender-sequence
```

兼容测试会验证多产品取景的保存与切换、旧版取景兼容、两种拍摄方式的预览与导出，以及 Blender 场景的合成与透明设置。网站读取导出序列，验证俯角、帧顺序、透明通道及按需 WebP 预览。扩展版本在 `glb_orbit_export/blender_manifest.toml` 中维护。
