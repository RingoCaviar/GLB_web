### 360° 图片序列

修改网页的序列目录、文件名、俯角、帧顺序或格式时，同步检查 `blender/glb_orbit_export/`。运行 `npm run test:sequence` 与 `npm run test:blender-sequence`。影响扩展时，更新扩展版本和使用说明并重建安装包，命令见 `blender/README.md`。
